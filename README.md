My entry for the make.fun competition "The Router Confesses": a program that writes a single line to `/output/entry.txt`. The excuse: **"I didn't crash — I peeked at the ending first: the dog dies, and I refuse to be the one who shows you."** — the router didn't fail, it read the ending ahead of time and chose not to be the bearer of the bad news.

## Run it

```sh
python3 main.py
```

This writes exactly one line (102 characters, no trailing newline) to `/output/entry.txt`.
